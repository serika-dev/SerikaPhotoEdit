# Serika PhotoEdit 0.0.1

**Initial public release — 8 October 2026**

Serika PhotoEdit is an open-source C++20/Qt Widgets photo editor with layered editing, masks, high-precision RGB and familiar Photoshop-style keyboard controls. Application code and original Serika icons are MIT licensed; bundled libraries retain their own licenses.

This is an early release with useful working workflows and documented limits. It does not provide full Photoshop parity.

Extract the whole portable archive, then run `bin/SerikaPhotoEdit.exe`. The runtime libraries are included. The MSI includes an optional SPE/PSD/PSB file-association feature. Both the executable and installer are **unsigned**.

See the [live release page](https://github.com/serika-dev/SerikaPhotoEdit/releases/tag/v0.0.1) for current download availability and the [live validation record](https://github.com/serika-dev/SerikaPhotoEdit/blob/main/docs/RELEASE-VALIDATION.md) for completed package checks. Additional platform packages extend this existing release using unchanged v0.0.1 application source with current packaging scripts, documentation and notices; the application tag and version are unchanged.

macOS: choose Intel or Apple Silicon, drag the app from the DMG to Applications, or extract the ZIP. The verified bundle minimums are macOS 15.0 for Intel and 14.0 for Apple Silicon, also recorded in each app's dependency manifest. Bundles include Qt/application libraries and use an ad-hoc signature, without Developer ID signing or notarization. First launch may require approval under System Settings → Privacy & Security; see [Apple's instructions](https://support.apple.com/en-us/102445).

Linux: target Ubuntu 24.04/glibc 2.39 or newer on the matching architecture. Make the AppImage executable and run it; without FUSE, use `--appimage-extract-and-run`. Alternatively, extract the tar.gz and use its top-level `SerikaPhotoEdit` launcher, or install the DEB with `sudo apt install ./SerikaPhotoEdit-0.0.1-linux-amd64.deb` (use `arm64` for ARM). Qt/application dependencies are bundled; glibc, graphics drivers, a desktop session and fonts remain host requirements. Other distributions are unverified.

Windows 11 x64 has native application and package validation. Earlier CI also built and passed offscreen tests on Windows Server 2022, macOS 14 and Ubuntu 24.04; those checks do not establish full interactive native acceptance. Windows ARM64 and other OS versions remain unverified.

## Included workflows

- Native document tabs, detachable windows, dockable panels, workspaces, command palette, four themes and original Serika artwork.
- 8-bit, 16-bit and float RGB layers and selections; copy-on-write history; groups, adjustments, effects, text/shapes and smart objects.
- Raster/vector masks with density, feather and linking; Select and Mask previews, edge brushing and output modes; saved selections and layer comps.
- Brush/eraser, clone/heal, fill/gradient, selections, paths/text/shapes, Liquify, guides/rulers and zoom/pan.
- Preview-first crop and perspective crop, ratios, output dimensions, overlays, straighten and automatic transparent/uniform-border bounds detection.
- Inline Free Transform, scale, rotation, affine skew and projective distort/perspective; selected-mask transforms; Patch and Content-Aware Move with transported pixels.
- Photoshop-style shortcuts with remapping, conflict detection, tool scopes/cycles, held modifiers and JSON import/export.
- SPE/SPEB saving, original PSD/PSB import/export, LibRaw RAW Develop, raster/TGA/HDR/SVG and PDF page imports.
- Retained-source smart-filter stacks, selectable History Brush sources, Fade, action playback and headless batch processing.

Use **SPE as the master format** for layered work. PSD/PSB compatibility uses raster fallback layers and private Serika tags for some editable data; it does not guarantee lossless interchange with another editor.

## Known limits

- No full Photoshop parity: specialist features and some tool algorithms are simplified.
- Content-aware operations use local CPU methods, without a trained semantic subject/fill model.
- Embedded smart-object subdocuments, comprehensive Adobe descriptors, advanced typography and multi-layer/group transforms remain incomplete.
- CMYK/Lab editing, professional ICC/proof workflows and GPU acceleration are limited or absent.
- Many operations allocate full images; the tiled model is not an out-of-core editor, and canvas creation is capped at 80 million pixels.
- Large external PSD/PSB files, camera-by-camera RAW coverage, tablets, mixed-DPI displays and full interactive native behavior outside Windows 11 require further validation.
- Normal DEB installation/uninstallation, Developer ID signing/notarization, universal Mac binaries and other Linux distributions remain unverified.

Details are in [current implementation status](https://github.com/serika-dev/SerikaPhotoEdit/blob/main/docs/IMPLEMENTATION-STATUS.md) and [format fidelity notes](https://github.com/serika-dev/SerikaPhotoEdit/blob/v0.0.1/src/io/README.md).
